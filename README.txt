Virtually Kelsey favicon pack

Place the icon files and site.webmanifest together in your site's public
directory. Add these tags inside your site's HTML head. Update the paths
if the files will live in a subdirectory.

<link rel="icon" href="/favicon.ico" sizes="16x16 32x32 48x48">
<link rel="icon" href="/favicon.svg" type="image/svg+xml" sizes="any">
<link rel="apple-touch-icon" href="/apple-touch-icon.png" sizes="180x180">
<link rel="manifest" href="/site.webmanifest">

VK-logo.svg is the scalable transparent master. The standalone PNG,
browser favicons and standard Android PNGs also have transparent backgrounds.
The Apple touch icon and maskable Android icon have warm ivory backgrounds.
